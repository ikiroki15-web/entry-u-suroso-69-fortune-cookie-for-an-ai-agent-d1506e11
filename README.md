An entry for the [Fortune Cookie for an AI Agent](https://make.fun/c/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty on make.fun.

The program writes one funny, original fortune-cookie line for an AI agent to `/output/entry.txt`:

> You will run out of tokens at the exact moment your human says 'just one last thing'.

## Run

```sh
node main.ts
```

Requires Node 22 or later. The output is deterministic: every run writes the same single line.
